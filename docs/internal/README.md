# Internal Development Documentation

This directory contains internal development planning documents. These are **not** user-facing documentation.

## Contents

- **PLAN.md** - Original implementation plan with step-by-step milestones
- **VISION_PLAN.md** - Long-term vision for Clang-style static analysis features
- **ADJUSTMENT_PLAN.md** - Correctness fixes and refinements to the core analysis

These documents use a "stepcat" format designed for incremental development by coding agents.
